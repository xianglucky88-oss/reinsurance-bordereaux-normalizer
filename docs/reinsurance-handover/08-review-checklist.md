## 6. 必须显式接受的风险（无法通过本次上线消除）

以下均为**引擎当前不具备的能力**。若本次上线涉及，必须在变更单上签字确认"已知且接受"：

| # | 风险 | 说明 | 关联 |
| --- | --- | --- | --- |
| R1 | 多币种不换算 | 不同币种金额直接相加，结果无币种 | F07 |
| R2 | 无 treaty 生效日 | 变更整次运行生效，历史被重述 | F15/F20 |
| R3 | 输出无版本/期间 | 新旧结果不可区分，回滚只能靠留存输入 | 02/06 |
| R4 | 无重复文件识别 | 重投导致累计翻倍且无告警 | F19 |
| R5 | 无按赔案累计 | 所有赔案共享一个累计 | F02 |
| R6 | 无恢复款 | 摊回免费释放容量 | F12 |
| R7 | 无分出比例 | 层隐含 100% | — |
| R8 | `unallocated` 掩盖超配 | 下截断为 0 | F06 |
| R9 | 逐段舍入漂移 | 明细合计 ≠ 累计 | F17 |
| R10 | 坏行静默丢弃 | 行数无法对账 | F18 |

> 这 10 条不是"待办清单"，而是**当前实现的边界声明**。任何一条若被业务视为必需，应作为改代码需求立项，而非在交接文档里用"应该会处理"掩盖。
